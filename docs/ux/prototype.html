  • Photography leads. The collage shows finished work across four textures before a single word.
  • Privacy in the first screen, not in a footer: it answers the worry before it forms.
  • Numbered steps are a real sequence, so the numbers carry meaning.
2Style quiz · tap through
  • One question a screen, answer-to-advance on single choices: no Next button to hunt for.
  • Hair type is a 2×2 grid of equal cards with drawn textures, so no type reads as the default. Curl codes appear only as a hint.
  • “Texture” is renamed strand thickness for clients and stylists: in textured-hair care, “texture” means curl pattern.
  • The past-stylist question becomes “What should your next stylist get right?” with their own words optional.
3Inspiration photo
  • Privacy promise sits under the picker, in a calm info tone, not a warning tone. Three short facts, each one true in the code today.
  • The retention number comes from the server setting, so the copy can’t drift from the job.
  • After picking: a preview with “Change photo”, and a nudge to send the look, not a selfie.
4Instant results ·
  • No “we’ll email you”. Ranking takes seconds, so the wait is a short, honest show on the same page: three real steps, the client’s own photo, and stylists’ work filling in.
  • The echo holds the wait: their own words in display italic, so the first thing after sending is proof they were heard.
  • The wait turns into the results in place: the placeholder tiles become the evidence photos, and the cards rise in one by one.
  • Recommendations first, “See all stylists” beside them as a tab. Book names the destination (“Book on Vagaro ↗”).
5See all stylists · filter
  • Clients choose. Every live stylist, filtered by service and hair type, starting from the client’s own answers.
  • Each card shows how much work they have per hair type (“Curly 14 · Coily 6”), the same evidence the recommendations use.
  • Recommended stylists carry a quiet label and sort first; nothing else is ranked by us, and there are no stars or prices to sort by.
  • “Sample stylist” labels a demo profile wherever a client could see it.
Stylist · signed in · phone, between clients

Your portfolio, tagged in a minute

Two thumbs, a few minutes between appointments. Tagging is the only work we ask of stylists, so each photo takes four taps and “Save and next”.

6Portfolio and tag sheet · tap a photo
  • Untagged photos wear a dashed outline and the bar counts them, so the next job is always visible.
  • Tag sheet order follows matching: service and hair type first (the two matching filters on), then strand thickness, length, before/after.
  • “Same as last photo” and “Save and next” make a batch from one appointment a few taps each.
  • Hair type uses the same glyphs and words as the client quiz, so both sides mean the same thing.
7Go-live checklist
  • One checklist, each row a link to the step that fixes it. The Go live button says exactly what’s missing.
  • The booking link shows the detected platform, so a wrong paste is caught here, not by a client.
  • “Your work by hair type” is informative, never a score: it shows what clients will be matched on.
Admin · desktop or tablet

Watch every match, step in after the fact

Matches publish automatically. The admin screen is a log: what each client was shown, what they clicked and booked, and fairness by hair type up top. Hide a match or a stylist after the fact. Turn on “Review before publish” to see the secondary approval state.

  • Fairness sits above the log, not two clicks away: a hair type falling behind is the first thing the admin sees each morning.
  • Every row answers “what did this client see, and did it work?”: shown, viewed, clicked, booked. Rows that need a look (few matches, a near-type match) carry a chip.
